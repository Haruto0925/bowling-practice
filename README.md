# ボウリング練習ノート(共有DB版)

社内ボウリングの練習記録・上達度・会場別スコア傾向を確認するPWAアプリです。
Firebase(Firestore) に記録が集まり、全員の端末にリアルタイム反映されます。

## 機能

- 練習記録(日付・メンバー・会場・最大10ゲーム・メモ)
- **クラウド共有**: 誰かが記録すると全端末に即時反映(Firestore)
- 上達度の可視化(初期5G平均→直近5G平均の比較、上達ランキング)
- スコア推移グラフ(5ゲーム移動平均つき)
- 会場別スコア傾向(平均・最高/最低・全体平均比・比較バーチャート)
- メンバー別絞り込み分析
- JSON バックアップ/復元、CSV出力(Excel用)
- オフライン閲覧対応(端末キャッシュ + Service Worker)
- Firebase未設定でもローカルモード(端末内保存)として動作

## 使い方

1. 「かんり」タブでメンバーと会場を登録(どの端末からでもOK・全員に共有)
2. 「きろく」タブで練習スコアを記録
3. 「ぶんせき」タブで上達度・会場別傾向を確認
